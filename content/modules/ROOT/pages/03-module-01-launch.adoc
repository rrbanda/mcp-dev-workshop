= Module 1: Launch Your Workspace
:navtitle: Launch Your Workspace

Get oriented in your cloud development environment before you start building.
This module ensures you can navigate the IDE, use the terminal, and confirm
the AI model responds -- the foundations you need for the rest of the workshop.

== Learning objectives

* Open a terminal in DevSpaces and run basic `oc` commands.
* Confirm the AI model responds to prompts.
* Locate the workshop files and skills in the project tree.
* _(Agent mode)_ Navigate the OpenCode Web UI and send a chat message.

== Exercise 1: Explore your workspace

[tabs]
====
Agent Mode::
+
--
Open the OpenCode Web UI from your workspace endpoints (port 4096). Enter the
password from your credentials card.

Take a moment to identify:

* *Chat panel* -- where you type prompts and see the agent's responses.
* *File context* -- the agent can read and write files in your project.
* *Tool indicators* -- when the agent uses a tool (write, edit, bash), you see
  the tool name in the response.

Type a simple message to verify the connection:

----
What directory am I in, and what files do you see?
----

Expected result: The agent responds describing the `/projects/mcp-dev-workshop`
directory and lists files like `scaffold/`, `Makefile`, `.opencode/skills/`, etc.

[IMPORTANT]
=====
If the agent returns a connection error or timeout, verify the model endpoint:

[source,bash,role="execute"]
----
echo $OPENAI_BASE_URL
----

This should print the MaaS gateway URL. If empty, contact the facilitator.
=====
--

Manual Mode::
+
--
Open a terminal in your DevSpaces workspace. You will use the terminal and
command-line tools for all exercises.

Verify the model endpoint is configured:

[source,bash,role="execute"]
----
echo $OPENAI_BASE_URL
----

Expected result: The MaaS gateway URL. If empty, contact the facilitator.

Quick test -- send a chat completion request:

[source,bash,role="execute"]
----
curl -s "$OPENAI_BASE_URL/chat/completions" \
  -H "Authorization: Bearer $OPENAI_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"model":"'"$OPENAI_MODEL"'","messages":[{"role":"user","content":"Say hello in one sentence."}],"max_tokens":50}' | python3 -m json.tool | grep -A2 '"content"'
----

Expected result: A JSON response with the model's reply.
--
====

== Exercise 2: Explore the terminal

Open a terminal in the IDE. Verify your identity and namespace:

[source,bash,role="execute"]
----
oc whoami
----

[source,bash,role="execute"]
----
oc project
----

Expected result: Your username and your DevSpaces namespace
(`<username>-devspaces`).

Check the AI serving namespace to see what is running:

[source,bash,role="execute",subs="attributes+"]
----
oc get pods -n {ai_namespace} | head -20
----

Expected result: You see vLLM pods, EPP pods, and other AI serving components
running. You have read access to the AI namespace but cannot modify it.

== Exercise 3: Browse the project structure

In the terminal, examine the workshop repo:

[source,bash,role="execute"]
----
find /projects/mcp-dev-workshop -maxdepth 3 -type f | head -30
----

Key directories:

* `.opencode/skills/` -- Skills that teach patterns and specifications:
** `build-mcp-server/` -- MCP Python SDK v2 patterns (MCPServer, decorators, transports)
** `yfinance-api/` -- Complete yfinance library API reference
** `stock-market-mcp-spec/` -- Exact specification for the stock market MCP server
* `scaffold/` -- reference files: a working server, Containerfile, deployment manifest.
* `solutions/` -- checkpoint solutions if you fall behind.
* `Makefile` -- workshop commands (`make validate`, `make deploy`, etc.).
* `content/` -- the Antora source for this workshop guide (you can ignore this).

[source,bash,role="execute"]
----
ls .opencode/skills/*/SKILL.md
----

Expected result: You see three skills -- `build-mcp-server`, `yfinance-api`,
and `stock-market-mcp-spec`.

== Exercise 4: Test the LLM connection

[tabs]
====
Agent Mode::
+
--
In the OpenCode chat, ask a coding question to make sure the model handles
code well:

----
Write a Python function that takes a list of pod names and returns the longest one. Just the function, nothing else.
----

Expected result: The agent writes a short Python function. This confirms the
full path works: OpenCode -> MaaS (API key auth) -> LLM -> response.
--

Manual Mode::
+
--
Use `curl` to test with a coding question:

[source,bash,role="execute"]
----
curl -s "$OPENAI_BASE_URL/chat/completions" \
  -H "Authorization: Bearer $OPENAI_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"model":"'"$OPENAI_MODEL"'","messages":[{"role":"user","content":"Write a Python function that takes a list of pod names and returns the longest one. Just the function."}],"max_tokens":200}' | python3 -m json.tool
----

Expected result: A JSON response containing a Python function. This confirms:
terminal -> MaaS (API key auth) -> LLM -> response.
--
====
