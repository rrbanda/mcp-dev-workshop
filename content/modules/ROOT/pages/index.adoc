= MCP Developer Workshop
:navtitle: Introduction

Build, test, and deploy an MCP server on OpenShift -- guided by an AI agent.

== What you will do

In this hands-on workshop, you build a real stock market MCP server with 9 tools, deploy it using the full MCP Lifecycle on OpenShift, and use it from an AI chat -- all guided by *AgentSherpa*, your personal AI workshop facilitator.

Everything runs inside a cloud workspace on a pre-configured OpenShift cluster. No local tooling required. You open a browser and start building.

== The AI-native software development lifecycle

This workshop demonstrates a new way of building software. Each stage maps to a phase of the *agentic SDLC*:

[cols="1,2,3",options="header"]
|===
| Stage | SDLC Phase | What happens

| 1. Welcome & Concepts
| --
| Meet AgentSherpa, learn MCP fundamentals

| 2. Capture Intent
| Intent
| Describe what you want to build, agent confirms

| 3. Skills & Knowledge
| Knowledge
| Agent loads domain skills, explains each one

| 4. Design
| Design
| Pick tools, confirm the server design

| 5. Plan
| Plan
| Review the build plan before any code is written

| 6. Build + Test
| Build

| 7. Deploy

| 8. Connect & Use

| 9. Wrap-up
| --
| Score, certificate, final quiz, cleanup
|===

== Your environment

Each participant gets a personal cloud workspace powered by *Red Hat OpenShift DevSpaces*. Inside that workspace you have:

* *OpenCode Web* -- an AI-native IDE with AgentSherpa pre-configured
* A *terminal* with `oc`, `python`, `pip`, and `curl` pre-installed and pre-authenticated
* *17 Agent Skills* that give AgentSherpa domain knowledge about MCP, yfinance, and OpenShift deployment

All you need is a web browser and the credentials your facilitator provides.

== How the workshop works

You interact with *AgentSherpa* in OpenCode's chat. The agent:

* Explains concepts before running commands (with analogies when helpful)
* Generates code and tests it with real stock data
* Deploys using MCPServer CRs (not manual Deployments)
* Asks for your input at every step -- you approve designs, plans, and actions
* Scores your progress (100 points) and generates a certificate at the end

The agent guides the pace. If you know MCP well, it moves faster. If you are new, it slows down and explains more.

== Learning objectives

By the end of the workshop you will be able to:

* Explain how MCP separates tool definitions from agent reasoning
* Build an MCP server using the Python SDK v2 with proper tool definitions and type hints
* Deploy an MCP server using the MCPServer CR and the MCP Lifecycle Operator
* Register a server with the MCP Gateway for federated tool discovery
* Use deployed MCP tools from an AI chat session
