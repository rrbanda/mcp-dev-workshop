= MCP Developer Workshop
:navtitle: Introduction

Build, deploy, and use an MCP server on OpenShift -- from code to production using the full MCP Lifecycle.

== What you will do

In this workshop you will take a pre-built stock market MCP server, build a container image, deploy it through the MCP Lifecycle Operator, register it with the MCP Gateway, and test it by speaking the MCP protocol directly with `curl`. By the end you will have a working MCP server accessible through the governed MCP Gateway -- and you will understand every layer of the stack.

== Two tracks

[cols="1,2",options="header"]
|===
| Track | How it works

| *xref:15-manual-track.adoc[Hands-on track]* (recommended)
| Pre-built server code with rich comments. You read the code, understand the RHOAI 3.5 MCP Lifecycle, then build and deploy using `oc` commands and test with `curl`. ~50 minutes.

| *Agent-guided track* (optional, Stages 1–9)
| AgentSherpa, an AI coding agent, walks you through the entire SDLC: intent → design → build → deploy → use. The agent generates code, runs tests, and deploys — you approve each step.
|===

Both tracks deploy the same stock market MCP server through the same MCP Lifecycle: *MCPServer CR → AI Hub → MCP Gateway*.

== Your environment

Each participant gets a personal cloud workspace powered by *Red Hat OpenShift DevSpaces*. Inside that workspace you have:

* A *terminal* with `oc`, `python`, `pip`, and `curl` pre-installed and pre-authenticated against the cluster
* The *workshop repository* cloned at `/projects/mcp-dev-workshop` with the server code in `server/` and deploy manifests in `deploy/`
* *OpenCode Web* (optional) -- an AI-native IDE with AgentSherpa pre-configured, for the agent-guided track

All you need is a web browser and the credentials your facilitator provides.

== Learning objectives

By the end of the workshop you will be able to:

* Explain how MCP separates tool definitions from agent reasoning
* Read and understand an MCP server built with the Python SDK v2
* Build a container image using OpenShift binary builds
* Deploy an MCP server using the MCPServer CR and the MCP Lifecycle Operator
* Register a server with the MCP Gateway for federated tool discovery
* Speak the MCP protocol (JSON-RPC 2.0) using `curl`: `initialize`, `tools/list`, `tools/call`
