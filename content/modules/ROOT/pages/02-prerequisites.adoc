= Prerequisites
:navtitle: Prerequisites

== What you need

* A web browser (Chrome, Firefox, or Edge)
* Workshop credentials from your facilitator: *OpenShift console URL*, *username*, *password*

No local tools, no IDE installation, no Docker or Podman.

== Step 1: Open your workspace

Your facilitator will provide a direct URL to your DevSpaces workspace. Open it in your browser and log in with your workshop credentials.

Once the workspace loads, open a *Terminal* (Terminal → New Terminal, or use the existing one).

== Step 2: Verify cluster connectivity

In the terminal, run:

[source,bash]
----
oc whoami
----

Expected: your username (e.g., `user1`) or service account.

[source,bash]
----
oc project
----

Expected: your namespace (e.g., `user1-devspaces`).

== Step 3: Verify the workshop repo

[source,bash]
----
ls /projects/mcp-dev-workshop/server/server.py
----

Expected: the file exists. This is the pre-built MCP server you will deploy.

== Step 4 (optional): Verify OpenCode Web

If you plan to follow the *agent-guided track*, your facilitator will provide a separate OpenCode Web URL. Open it and log in with:

* *Username:* `opencode`
* *Password:* the AgentSherpa password from your credentials card

Type anything (e.g., "hello") and press Enter. AgentSherpa should respond with a welcome message.

== Troubleshooting

[cols="1,2",options="header"]
|===
| Issue | Resolution

| Blank screen after login
| Clear browser cache and reload. If the workspace is stopped, ask the facilitator to start it.

| `oc whoami` fails
| The workspace credentials are injected automatically. If missing, the workspace may need a restart — ask the facilitator.

| Workshop repo missing
| Run `cd /projects && git clone <repo-url>` (ask your facilitator for the URL).

| "401 Unauthorized" on OpenCode Web
| Double-check the AgentSherpa password. Username is always `opencode`.

| No response from AgentSherpa
| Check that `OPENAI_BASE_URL` is set in the OpenCode terminal. The LLM may still be loading — wait 1-2 minutes and try again.
|===
