= Prerequisites
:navtitle: Prerequisites

== What you need

* A web browser (Chrome, Firefox, or Edge)
* Workshop credentials from your facilitator: *OpenShift console URL*, *username*, *password*, and *AgentSherpa password*

No local tools, no IDE installation, no Docker or Podman.

== Step 1: Open OpenCode Web

Your facilitator will provide a direct URL to your OpenCode Web workspace, for example:

----
https://user1-code-workspace-1-opencode-web.apps.<cluster-domain>
----

Open this URL in your browser. Log in with:

* *Username:* `opencode`
* *Password:* the AgentSherpa password from your credentials card

== Step 2: Verify the workspace

Once OpenCode loads, you should see:

* A chat interface with an input box at the bottom
* A sidebar showing sessions and tools

Type anything (e.g., "hello") and press Enter. AgentSherpa should respond with its welcome message and present four options via clickable buttons.

If you see the welcome message, your workspace is ready.

== Step 3: Verify cluster connectivity

Open the terminal in OpenCode (or use the bash tool in chat) and run:

[source,bash]
----
oc whoami
----

Expected: your service account name (e.g., `system:serviceaccount:user1-devspaces:...`).

[source,bash]
----
echo $OPENAI_BASE_URL
----

Expected: the MaaS gateway URL for the LLM.

== Troubleshooting

[cols="1,2",options="header"]
|===
| Issue | Resolution

| Blank screen after login
| Clear browser cache and reload. If the workspace is stopped, ask the facilitator to start it.

| "401 Unauthorized" on login
| Double-check the AgentSherpa password from your credentials card. Username is always `opencode`.

| `oc whoami` fails
| The workspace service account token is injected automatically. If missing, the workspace may need a restart.

| No response from AgentSherpa
| Check that `OPENAI_BASE_URL` is set. The LLM may still be loading -- wait 1-2 minutes and try again.
|===
