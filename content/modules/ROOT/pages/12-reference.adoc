=== Transport modes

[cols="1,2,2",options="header"]
|===
| Transport | Code | Use case

| stdio
| `server.run()`
| Local development, agent-direct connection

| streamable-http
| `server.run(transport="streamable-http", host="0.0.0.0", port=8080)`
| Container deployment on OpenShift

| ASGI (uvicorn)
| `app = server.streamable_http_app(stateless_http=True, json_response=True)`
| Production with process manager
|===

=== Type hint → JSON Schema mapping

[cols="1,1",options="header"]
|===
| Python type | JSON Schema

| `str` | `{"type": "string"}`
| `int` | `{"type": "integer"}`
| `float` | `{"type": "number"}`
| `bool` | `{"type": "boolean"}`
| `float \| None` | `{"type": "number"}` (nullable)
| `list[str]` | `{"type": "array", "items": {"type": "string"}}`
| `list[str] \| None` | `{"type": "array"}` (nullable)
| `str, Enum` subclass | `{"enum": ["val1", "val2", ...]}`
| default value | sets `"required": false`
|===

== Deployment manifest reference

=== Deployment + Service (recommended for production)

[source,yaml]
----
apiVersion: apps/v1
kind: Deployment
metadata:
  name: stock-market-mcp
  labels:
    app: stock-market-mcp
spec:
  replicas: 1
  selector:
    matchLabels:
      app: stock-market-mcp
  template:
    metadata:
      labels:
        app: stock-market-mcp
    spec:
      containers:
        - name: server
          image: image-registry.openshift-image-registry.svc:5000/<namespace>/stock-market-mcp:latest
          ports:
            - containerPort: 8080
          env:
            - name: MCP_TRANSPORT
              value: "streamable-http"
          readinessProbe:
            tcpSocket:
              port: 8080
            initialDelaySeconds: 10
            periodSeconds: 10
          resources:
            requests:
              memory: "256Mi"
              cpu: "200m"
            limits:
              memory: "512Mi"
              cpu: "1000m"
---
apiVersion: v1
kind: Service
metadata:
  name: stock-market-mcp
spec:
  selector:
    app: stock-market-mcp
  ports:
    - port: 8080
      targetPort: 8080
----

=== MCPServer CRD (Technology Preview, RHOAI 3.5)

[source,yaml]
----
apiVersion: mcp.x-k8s.io/v1alpha1
kind: MCPServer
metadata:
  name: stock-market-mcp
spec:
  source:
    type: ContainerImage
    containerImage:
      ref: image-registry.openshift-image-registry.svc:5000/<namespace>/stock-market-mcp:latest
  config:
    port: 8080
----

NOTE: Technology Preview (`v1alpha1`). No backward compatibility commitment.
Enable via DataScienceCluster patch:
`spec.components.mcplifecycleoperator.managementState: Managed`.
The operator creates the Deployment, Service, and NetworkPolicy automatically.
Use Deployment + Service for production.

== Containerfile reference

[source,dockerfile]
----
FROM registry.access.redhat.com/ubi9/python-312:latest

WORKDIR /opt/app-root/src
COPY requirements.txt .
RUN pip install --no-cache-dir -r requirements.txt
COPY server.py .

ENV MCP_TRANSPORT=streamable-http
EXPOSE 8080
CMD ["python", "server.py"]
----
