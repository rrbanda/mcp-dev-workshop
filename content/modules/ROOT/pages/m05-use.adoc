= Call Tools with curl
:navtitle: Call Tools with curl

The final step: connect to the MCP server you just deployed and call its tools
using `curl` and the JSON-RPC protocol. You will initialize a session, list
tools, and call them directly -- no AI agent involved.

== Learning objectives

* Call MCP tools using `curl` and the JSON-RPC protocol.
* Understand the MCP session lifecycle: initialize, list tools, call tools.
* Reflect on the full developer loop: build, test, deploy, use.

== Exercise 1: Get the service URL

Your MCP server is running as a ClusterIP Service. From inside the cluster
(which is where your DevSpaces workspace runs), you can reach it directly:

[source,bash,role="execute"]
----
NAMESPACE=$(oc project -q)
echo "http://stock-market-mcp.${NAMESPACE}.svc:8080/mcp"
----

== Exercise 2: Initialize an MCP session

Use `curl` to call the MCP server directly. First, initialize a session:

[source,bash,role="execute"]
----
NAMESPACE=$(oc project -q)
MCP_URL="http://stock-market-mcp.${NAMESPACE}.svc:8080/mcp"

curl -sD /tmp/mcp-headers -X POST "$MCP_URL" \
  -H "Content-Type: application/json" \
  -d '{"jsonrpc":"2.0","id":1,"method":"initialize","params":{"protocolVersion":"2025-03-26","capabilities":{},"clientInfo":{"name":"workshop","version":"1.0"}}}'

echo ""
echo "Session ID:"
grep -i mcp-session-id /tmp/mcp-headers
----

Expected result: A JSON-RPC response with protocol version and server
capabilities, plus a `Mcp-Session-Id` header.

== Exercise 3: List available tools

[source,bash,role="execute"]
----
SESSION=$(grep -i mcp-session-id /tmp/mcp-headers | tr -d '\r' | awk '{print $2}')

curl -s -X POST "$MCP_URL" \
  -H "Content-Type: application/json" \
  -H "Mcp-Session-Id: $SESSION" \
  -d '{"jsonrpc":"2.0","id":2,"method":"tools/list","params":{}}' | python3 -m json.tool | head -30
----

Expected result: A list of 9 tools with their names and JSON Schema parameters.

== Exercise 4: Call tools

Get Apple's stock info:

[source,bash,role="execute"]
----
curl -s -X POST "$MCP_URL" \
  -H "Content-Type: application/json" \
  -H "Mcp-Session-Id: $SESSION" \
  -d '{"jsonrpc":"2.0","id":3,"method":"tools/call","params":{"name":"get_stock_info","arguments":{"ticker":"AAPL"}}}' | python3 -m json.tool
----

Expected result: Real stock data for Apple -- current price, market cap,
P/E ratio, 52-week range, and more.

Try another tool -- analyst recommendations:

[source,bash,role="execute"]
----
curl -s -X POST "$MCP_URL" \
  -H "Content-Type: application/json" \
  -H "Mcp-Session-Id: $SESSION" \
  -d '{"jsonrpc":"2.0","id":4,"method":"tools/call","params":{"name":"get_recommendations","arguments":{"ticker":"MSFT","recommendation_type":"recommendations"}}}' | python3 -m json.tool
----

Or use the Makefile shortcut:

[source,bash,role="execute"]
----
make test-mcp
----
