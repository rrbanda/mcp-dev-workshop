= Cleanup
:navtitle: Cleanup

Remove the resources you created during the workshop to free cluster capacity
for the next session.

== Delete your MCP server deployment

[source,bash,role="execute"]
----
cd /projects/mcp-dev-workshop
make clean
----

Or manually:

[source,bash,role="execute"]
----
oc delete deployment stock-market-mcp --ignore-not-found
oc delete service stock-market-mcp --ignore-not-found
oc delete bc stock-market-mcp --ignore-not-found
oc delete is stock-market-mcp --ignore-not-found
----

== Verify cleanup

[source,bash,role="execute"]
----
oc get all -l app=stock-market-mcp
----

Expected result: `No resources found` — everything is deleted.

== Stop your workspace

In the DevSpaces dashboard, click *Stop* on your workspace. This releases the
compute resources (CPU, memory) used by the workspace pod.

[NOTE]
====
The facilitator may clean up namespaces after the workshop. Your workspace data
is stored on a PVC and survives workspace restarts, but may be deleted when the
namespace is removed.
====

== Thank you

Thank you for attending the workshop. Key takeaways:

* MCP provides a standard protocol for tool communication -- any client can
  call any server using the same JSON-RPC interface.
* The MCP Python SDK v2 makes it straightforward to define typed tools with
  decorators, Enums, and transport selection.
* The developer loop -- build, test, deploy, use -- can be completed in under
  90 minutes on OpenShift.
* _(Agent mode)_ Agent Skills teach AI agents new capabilities without
  retraining -- just add a Markdown file to your repo.
* OpenShift DevSpaces provides a zero-install cloud IDE for the entire workflow.
* Enterprise governance (RBAC, audit, PII redaction) is essential for
  production MCP deployments.
